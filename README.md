# Karissma Quinones — Portfolio

Personal portfolio site. Single static file (`index.html`), no build step.

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a public repo named `Karissma24.github.io` on GitHub.
2. Push `index.html` and this README to the `main` branch.
3. The site goes live at [https://karissma24.github.io](https://karissma24.github.io/karissmaq-portfolio/)


## Updating content
- **Resume:** replace `Karissma-Quinones-Resume.pdf` with a newer version (keep the same file name).
- **Live demo links:** in `index.html`, find `data-demo` and put the demo URL in that button's `href=""`.
- **Screenshots:** add images to an `images/` folder and follow the comment above each project card.
- **Headshot:** save your photo as `images/headshot.jpg` (square crop works best). Until then your initials show.
